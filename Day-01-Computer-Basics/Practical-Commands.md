# Day 01 - Practical Commands

## 1. System Information

```cmd
systeminfo
```

**Purpose:**

Displays detailed information about the Windows system.

---

## 2. IP Configuration

```cmd
ipconfig
```

**Purpose:**

Displays network configuration information.

---

## 3. Computer Name

```cmd
hostname
```

**Purpose:**

Displays the computer hostname.

---

## 4. Running Processes

```cmd
tasklist
```

**Purpose:**

Displays currently running processes.

---

## 5. Task Manager

**Shortcut:**

```text
Ctrl + Shift + Esc
```

**Used to observe:**

- CPU
- Memory
- Disk
- Network
- Running Processes
