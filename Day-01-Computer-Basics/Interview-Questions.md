# Day 01 - Interview Questions

## 1. What is an application?

An application is a software program designed to perform
a specific task for the user.

## 2. What is a process?

A process is a running instance of a program.

## 3. What is a file?

A file is a unit of stored data used to save information.

## 4. What is a folder?

A folder is used to organize and store files and subfolders.

## 5. Give examples of operating systems.

- Windows
- Linux
- macOS
- Android
- iOS

## 6. Why is Linux important for cybersecurity?

Linux is important for cybersecurity because it provides
powerful command-line tools, networking utilities, security
tools, and scripting capabilities.
