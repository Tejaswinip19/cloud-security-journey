# Day 01 Notes - Computer Fundamentals

## 1. What is a Computer?

A computer is an electronic device that accepts input,
processes data, produces output, and stores information.

## 2. Hardware

Hardware refers to the physical components of a computer.

Examples:
- CPU
- RAM
- SSD
- Keyboard
- Mouse
- Monitor

## 3. Software

Software consists of programs and instructions that tell
the computer what to do.

Examples:
- Windows
- Linux
- Chrome
- VS Code

## 4. Operating System

An operating system manages computer hardware and provides
services for applications.

Examples:
- Windows
- Linux
- macOS
- Android
- iOS

## 5. CPU

CPU stands for Central Processing Unit.
It executes instructions and performs calculations.

## 6. RAM

RAM stands for Random Access Memory.
It is temporary working memory used by running programs.

## 7. Storage

Storage is used to permanently store data and programs.

Examples:
- HDD
- SSD
- NVMe

## 8. Application

An application is software designed to perform a specific
task for the user.

Examples:
- Chrome
- VS Code
- Calculator

## 9. Process

A process is a running instance of a program.

## 10. File

A file is a unit of stored data.

Examples:
- resume.pdf
- notes.txt
- program.py

## 11. Folder

A folder is used to organize files and other folders.

## 12. Server

A server is a computer or system that provides services
or resources to clients.

## 13. Client

A client is a device or application that requests services
from a server.
